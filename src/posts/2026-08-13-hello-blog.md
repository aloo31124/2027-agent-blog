這是這個部落格的第一篇文章。

## 它是怎麼運作的

公開網站是**純靜態**的——沒有資料庫，也沒有應用伺服器。每一篇文章都只是一個 Markdown 檔案，存在 Git 倉庫裡。

但寫文章不需要打開編輯器改檔案。後台在 `/admin/`，用 GitHub 帳號登入後就能在瀏覽器裡寫，手機也可以。按下發佈之後，建置流程會自動跑起來，把網站重新產生一次再送上線。

## 三種狀態

| 狀態 | 意思 |
| --- | --- |
| 草稿 | 只有自己看得到，公開網站上完全不存在 |
| 待審核 | 已送出，等管理員核可 |
| 已發佈 | 讀者可以讀到 |

草稿不是「藏起來」——它根本不會產生檔案，所以就算有人猜到網址，得到的也是找不到頁面。

## 發佈前會先檢查

每次上線前都會先驗證一輪：關鍵頁面是否都產生了、彼此連得到嗎、草稿有沒有不小心外洩。**沒通過就不會取代線上版本**，所以失敗的時候讀者看到的仍然是前一個好的版本。
